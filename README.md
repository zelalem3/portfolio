# Zelalem Getnet — Portfolio

Personal portfolio website of **Zelalem Getnet**, Software Engineer focused on backend development and distributed systems.

## Live Demo

`https://zelalem3.github.io/portfolio`

## Tech

- Pure HTML, CSS & JavaScript (no frameworks)
- Responsive design
- Light / Dark mode
- Fast & accessible

## How to use

1. Create a new repository on GitHub named `portfolio` (or any name you like)
2. Push these files to the repository
3. Go to **Settings → Pages**
4. Under "Source" choose **Deploy from a branch** → `main` → `/ (root)`
5. Save. Your site will be live in 1–2 minutes.

### Optional: Custom domain

Add a `CNAME` file with your domain or configure it in the Pages settings.

## Customize

- Update project GitHub & Live Demo links in `index.html`
- Replace placeholder links with your real project repositories
- Edit colors in `styles.css` under the `:root` variables
